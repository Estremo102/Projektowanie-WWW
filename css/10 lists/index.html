Listy w HTML

W HTML mamy listy ol - numerowane i ul - punktowane, stylować je możemy za pomocą:

  • list-style-type
  • list-style-image
  • list-style-position
  • list-style

Zdefiniujmy kilka klas i zobaczmy jak wyglądają listy które z nich korzystają

  1. ol.a {list-style-type: upper-roman;}
  2. ol.b {list-style-type: lower-roman;}
  3. ol.c {list-style-type: lower-alpha;}
  4. ol.d {list-style-type: decimal;}

  • ul.e {list-style-type: circle}
  • ul.f {list-style-type: disc}
  • ul.g {list-style-type: square}
