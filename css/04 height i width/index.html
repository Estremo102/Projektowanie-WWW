Wysokość i szerokość elementnów

właściwości height i width

Aby ustawić wysokość i szerokość elementów, używamy właściwości height dla wysokości i width dla długości.

Przydadzą się tutaj ramki, lub tła elementów, żeby lepiej widzieć jak zmienia się ich rozmiar.
